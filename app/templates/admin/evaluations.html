Evaluation Framework & Metrics
1. Groundedness (Faithfulness)

Measures whether all claims made in the AI response can be mathematically verified by the retrieved source documents. Strict anti-hallucination prompts enforce a >95% score.

2. Context Relevance

Evaluates whether the vector store retrieved only chunks necessary to address the student question, minimizing noise and token cost.

3. Source Citation Precision

Ensures that every cited document, section title, and page number directly corroborates the factual statements in the answer.

4. No-Answer Detection (Refusal Rate)

Tests whether the model reliably refuses to answer questions about non-existent policies, unknown dates, or off-topic queries instead of inventing facts.
